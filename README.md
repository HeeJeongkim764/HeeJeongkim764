## 안녕하세요, 김희정입니다 👋

충남대학교 생명정보융합학과에서 **RNA와 후성유전체**를 전산으로 분석하고 있습니다.
비암호화 영역(인핸서, eRNA)이 유전자 조절과 질병에 어떻게 관여하는지에 관심이 많습니다.

### 🔬 관심 분야
- 비암호화 변이 효과 예측 (AlphaGenome, Borzoi, Enformer, Sei)
- 인핸서와 eRNA, 후성유전체 데이터 분석 (ENCODE cCRE)
- 노화와 세포 리프로그래밍의 유전체적 기반
